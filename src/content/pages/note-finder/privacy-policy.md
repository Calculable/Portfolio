# NoteFinder AI - App: <br>Privacy Policy

NoteFinder AI (“the App”) runs locally on your Mac. The App processes notes from folders you select and (optionally) uses OpenAI to generate summaries and perform AI Search. This document explains what data the App processes and what is shared.

<strong>Summary</strong>

- The App processes your notes locally on your Mac.
- The App stores an index of your notes locally on your Mac (so it can load quickly after restarts).
- If you enable AI features by providing an OpenAI API key, the App sends your note data to OpenAI’s API for summarization and AI Search. In practice, this can include the full content of your notes.
- OpenAI API usage may generate costs on **<strong>your</strong>** OpenAI account.
- Do not enable AI features for content you don’t want to share with OpenAI.

<strong>Data the App accesses on your Mac</strong>

When you select a directory in Settings, the App gets permission (a security-scoped bookmark) to access that directory across restarts.

<strong>The App may read:</strong>

- folder names and file names inside the selected directories
- textfiles inside those folders
- optional metadata files inside some note libraries (used to preserve ordering)

<strong>We do not collect or have access to your personal data recorded in the app “NoteFinder AI“ for macOS</strong>

The App runs locally on your Mac. The developer of NoteFinder AI does not operate a backend service for the App and does not receive your notes, your searches, or your API key through the App.

<strong>Apple-provided data (App Store Connect)</strong>

Apple provides certain usage and device data automatically through App Store Connect for all apps. This includes information like app performance, crash reports, and general interaction data, which is collected to improve user experience and app functionality. The data cannot be used to identify you. Please refer to Apple’s Privacy Policy for more details on how this data is managed and used:

<a href="https://www.apple.com/legal/privacy/en-ww/">https://www.apple.com/legal/privacy/en-ww/</a>

<strong>Data the App stores locally</strong>

The App stores locally on your Mac:

- an index of your notes (titles, extracted headlines, tags)
- AI-generated summaries
- app settings (like “do not show again” flags and selected model choices)

The App stores your OpenAI API key in the **<strong>macOS Keychain</strong>** (not in plain text files).

<strong>Data shared with OpenAI (optional)</strong>

If you provide an OpenAI API key and use AI features (summaries or AI Search), the App sends data to OpenAI, which can include:

- note text (Markdown content), possibly truncated in some cases
- note metadata needed for search (title, headlines, tags, summaries)
- your query text (what you typed into search)

This may include sensitive information if your notes contain it.

OpenAI is a third-party service. Their processing, retention, and security practices are governed by OpenAI’s own policies and terms. You should review them before using the App.

<strong>Costs</strong>

The App does not control OpenAI pricing. Any API usage costs are charged by OpenAI to the account associated with the API key you provide.

<strong>Your choices</strong>

- You can remove the saved API key in Settings.
- You can reset the index in Settings to delete the locally stored index and summaries.

<strong>Contact</strong>

If you have any questions about this Privacy Policy, reach out by <a href="/note-finder/contact">using the contact form</a>.
